Menambah Admin Lain

Minta orangnya login ke toko sekali, lalu jalankan perintah ini di Supabase → SQL Editor (ganti emailnya):

insert into public.admins (user_id)
select id from auth.users where email = 'email-admin@gmail.com'
on conflict do nothing;
